Create a new AI agent in your account. Supply a name and, optionally, a system prompt via the `instructions` field to define the agent's persona and behavior. By default, newly created agents are set to `inactive` — you can either pass `"status": "active"` at creation time or activate the agent later via the [Update Agent](/api-reference/agents/update) endpoint.

A successful request returns the full agent object with HTTP status `201 Created`.

```http
POST /v1/agents
```

## Request Body

<ParamField body="name" type="string" required>
  A human-readable display name for the agent. Maximum 100 characters.
</ParamField>

<ParamField body="instructions" type="string">
  The system prompt that governs the agent's behavior and persona. Maximum 4000 characters. If omitted, the agent will use default behavior with no custom instructions.
</ParamField>

<ParamField body="status" type="string">
  The initial status of the agent. Accepted values: `active` or `inactive`. Defaults to `inactive`.
</ParamField>

## Example Request

```bash
curl -X POST https://api.maislinda.com/v1/agents \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Support Bot",
    "instructions": "You are a helpful support agent. Answer questions clearly and concisely.",
    "status": "active"
  }'
```

## Example Response

```json
{
  "id": "agent_01j8x...",
  "name": "Support Bot",
  "instructions": "You are a helpful support agent. Answer questions clearly and concisely.",
  "status": "active",
  "created_at": "2024-01-15T10:30:00Z",
  "updated_at": "2024-01-15T10:30:00Z"
}
```

## Response Fields

<ResponseField name="id" type="string">
  The unique identifier assigned to the newly created agent. Store this value — it is required for all subsequent operations on this agent.
</ResponseField>

<ResponseField name="name" type="string">
  The display name of the agent as provided in the request.
</ResponseField>

<ResponseField name="instructions" type="string">
  The system prompt governing the agent's behavior. `null` if no instructions were provided.
</ResponseField>

<ResponseField name="status" type="string">
  The current status of the agent. Either `active` or `inactive`.
</ResponseField>

<ResponseField name="created_at" type="string">
  ISO 8601 timestamp of when the agent was created.
</ResponseField>

<ResponseField name="updated_at" type="string">
  ISO 8601 timestamp of the most recent update to the agent. Matches `created_at` for newly created agents.
</ResponseField>
