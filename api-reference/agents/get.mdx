Retrieve the complete details of a single agent by its unique ID. The response includes the agent's display name, system prompt instructions, current status, and creation and update timestamps.

Returns `404 NOT_FOUND` if no agent with the given ID exists in your account.

```http
GET /v1/agents/{agentId}
```

## Path Parameters

<ParamField path="agentId" type="string" required>
  The unique identifier of the agent to retrieve. Agent IDs are returned when [creating an agent](/api-reference/agents/create) or [listing agents](/api-reference/agents/list).
</ParamField>

## Example Request

```bash
curl https://api.maislinda.com/v1/agents/agent_01j8x... \
  -H "Authorization: Bearer YOUR_API_KEY"
```

## Example Response

```json
{
  "id": "agent_01j8x...",
  "name": "Support Bot",
  "instructions": "You are a helpful support agent. Answer questions clearly and concisely.",
  "status": "active",
  "created_at": "2024-01-15T10:30:00Z",
  "updated_at": "2024-01-16T08:00:00Z"
}
```

## Response Fields

<ResponseField name="id" type="string">
  The unique identifier of the agent.
</ResponseField>

<ResponseField name="name" type="string">
  The display name of the agent.
</ResponseField>

<ResponseField name="instructions" type="string">
  The system prompt governing the agent's behavior. `null` if no instructions have been set.
</ResponseField>

<ResponseField name="status" type="string">
  The current status of the agent. Either `active` or `inactive`.
</ResponseField>

<ResponseField name="created_at" type="string">
  ISO 8601 timestamp of when the agent was created.
</ResponseField>

<ResponseField name="updated_at" type="string">
  ISO 8601 timestamp of the most recent update to the agent.
</ResponseField>
