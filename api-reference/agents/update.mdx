---
title: "Update an Existing Agent — PATCH /v1/agents/{agentId}"
sidebarTitle: "Update Agent"
description: "Update an agent's name, system instructions, or status with partial update semantics — only the fields you include in the request are changed."
---

Update one or more fields on an existing agent. This endpoint uses **partial update** semantics — only the fields you include in the request body are modified. Fields you omit remain exactly as they are. This makes it safe to, for example, toggle an agent's status without accidentally overwriting its instructions.

A successful request returns the full updated agent object with HTTP status `200 OK`.

```http
PATCH /v1/agents/{agentId}
```

## Path Parameters

<ParamField path="agentId" type="string" required>
  The unique identifier of the agent to update.
</ParamField>

## Request Body

All body fields are optional. Include only the fields you want to change.

<ParamField body="name" type="string">
  A new display name for the agent. Maximum 100 characters.
</ParamField>

<ParamField body="instructions" type="string">
  A new system prompt to replace the agent's current instructions. Maximum 4000 characters. Pass `null` to clear existing instructions.
</ParamField>

<ParamField body="status" type="string">
  The new status for the agent. Accepted values: `active` or `inactive`.
</ParamField>

## Example Request

```bash
curl -X PATCH https://api.maislinda.com/v1/agents/agent_01j8x... \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "status": "active" }'
```

## Example Response

```json
{
  "id": "agent_01j8x...",
  "name": "Support Bot",
  "instructions": "You are a helpful support agent. Answer questions clearly and concisely.",
  "status": "active",
  "created_at": "2024-01-15T10:30:00Z",
  "updated_at": "2024-01-17T14:22:00Z"
}
```

## Response Fields

<ResponseField name="id" type="string">
  The unique identifier of the agent.
</ResponseField>

<ResponseField name="name" type="string">
  The display name of the agent, reflecting any update made in this request.
</ResponseField>

<ResponseField name="instructions" type="string">
  The system prompt governing the agent's behavior, reflecting any update made in this request. `null` if no instructions are set.
</ResponseField>

<ResponseField name="status" type="string">
  The current status of the agent. Either `active` or `inactive`.
</ResponseField>

<ResponseField name="created_at" type="string">
  ISO 8601 timestamp of when the agent was originally created. Never changes.
</ResponseField>

<ResponseField name="updated_at" type="string">
  ISO 8601 timestamp of this update.
</ResponseField>

<Note>
  Updating `instructions` takes effect immediately for new conversations. In-progress conversations retain the previous instructions until they conclude.
</Note>
