Whether you want to embed a chat widget on your website, connect to WhatsApp, or build a fully custom chat interface, Mais Linda handles the AI and conversation management so you can focus on your product.

## How It Works

<Steps>
  <Step title="Create an Agent">
    Use the API or dashboard to create an agent. Give it a name, instructions, and a knowledge base with your content.
  </Step>
  <Step title="Authenticate">
    Generate an API key from your dashboard and include it in your request headers.
  </Step>
  <Step title="Send Messages">
    Call the `/chat` endpoint with a user message and receive an AI-generated response with conversation threading built in.
  </Step>
  <Step title="Deploy Everywhere">
    Embed the chat widget on your site, connect messaging channels, or build your own UI on top of the API.
  </Step>
</Steps>

## Base URL

All API requests are made to:

```
https://api.maislinda.com/v1
```

Every request must include your API key in the `Authorization` header. See [Authentication](/authentication) for details.
